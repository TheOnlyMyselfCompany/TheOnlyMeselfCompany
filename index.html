About

How I build

💡 Ideas first

Every project starts with a small everyday problem — "what can I cook with what's in the fridge?" — and turns it into something people can actually open and use, not just a mockup.

🧰 Built simple, on purpose

Everything here is plain HTML, CSS and JavaScript in a single file per project. No servers, no accounts, no trackers. Your data stays in your own browser.

HTMLCSSJavaScriptGitHub PagesPWA-ready

🔗 They work together

  • Fridge Chef and Calorie Chef share the same chef profiles — pick a name once, it follows you.
  • Finish a recipe in Fridge Chef, tap log this meal, and it lands in Calorie Chef with the calories filled in.
  • Dark / light theme is set once and every project follows it — including this page.

📱 Add to your home screen

On a phone, open any project → browser menu → Add to Home Screen. It opens full-screen like an app.
